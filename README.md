## Projects

### 1. Smart Student Identification Card

The Smart Student Identification Card project is an IoT-based project designed to improve student identification and information management.

The project explores the use of technology to make student identification more efficient and provide useful student-related information.

**Technologies:**

* IoT
* Microcontrollers
* RFID/Identification Technology
* Database
* Web Technologies

### 2. IoT-Based Accident Detection and Emergency Alert System

This project focuses on detecting vehicle accidents using sensors and automatically generating emergency alerts.

The system is designed to detect accident conditions, determine the severity of an incident, obtain location information, and notify relevant emergency contacts.

**Technologies:**

* IoT
* Sensors
* GPS
* Microcontrollers
* GSM
* Embedded Systems
* Data Processing

### 3. Smart Room Temperature Controller

The Smart Room Temperature Controller is an embedded system designed to monitor and control room temperature automatically.

The system can use a temperature sensor to measure temperature and control devices such as a fan or heating device according to a defined temperature threshold.

**Technologies:**

* ATmega Microcontroller
* Temperature Sensor
* LCD
* Fan
* Heating Device
* Push Buttons
* Embedded C

### 4. IoT Alcohol and Health Monitoring System

This project demonstrates an IoT-based monitoring system that can collect different sensor readings and display the results through an LCD interface.

The system can use indicators such as LEDs and a buzzer to provide alerts when a predefined condition is detected.

**Technologies:**

* Arduino
* Sensors
* LCD
* Buzzer
* LEDs
* IoT

### 5. Traffic Light Control System

This project demonstrates the operation of a traffic light system using a microcontroller.

The system controls red, yellow, and green LEDs according to predefined time intervals.

**Technologies:**

* Arduino
* LEDs
* Embedded C/C++
* Microcontroller
